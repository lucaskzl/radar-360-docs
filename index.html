■ Capítulo 01 — Contexto e Problema
🚨
O Desafio
Cenário da Operação de TI

A Central de Atendimento do INCRA (Positivo S+) enfrentava uma limitação crítica: o sistema Cervello ESM não oferecia nativamente uma visão clara em tempo real do SLA (Service Level Agreement). Isso resultava em chamados vencendo sem alerta, impactando indicadores contratuais.

Além disso, respostas redigidas do zero e a ausência de dashboards individuais de produtividade engessavam o trabalho dos analistas de N2.

Chamados vencendo sem alertas visuais ou sonoros.
Tempo excessivo na triagem e redação de e-mails.
Dificuldade na mensuração de produtividade por turno.
■ Capítulo 02 — A Solução
🚀
Arquitetura
RADAR 360 — Hub Integrado

O RADAR 360 é uma Extensão Nativa (Google Chrome) que atua como uma camada de inteligência Front-end. Injetada diretamente via DOM Manipulation, ela processa dados em background sem exigir alterações no servidor ou banco de dados do cliente.

Motor SLA

Lê chamados via API REST a cada 10s e categoriza urgências.

RPA Scripts

Autopreenchimento de dados extraídos da tela (Regex).

Telemetria BI

Armazena métricas de fechamento no LocalStorage.

■ Capítulo 03 — UI Design (Hub Principal)

O Design System proprietário foi focado na estética de Glassmorphism e organizado num Bento Grid CSS. Ele atua como o menu central flutuante para o analista, adaptando-se instantaneamente ao tema (Claro/Escuro).

■ Capítulo 07 — Stack Tecnológico & CSS Variables

Toda a interface apresentada utiliza variáveis CSS injetadas no :root da página original. Isso permitiu a criação de um sistema de cores responsivo Light / Dark Mode sem recarregar a página.

💡 Experimente clicar no botão "Modo Noturno / Claro" no topo desta página para ver a troca de escopo funcionando em tempo real.

JavaScript ES6+
Core logic encapsulada via IIFE, requisições Fetch assíncronas, manipulação de DOM e Regex.
Chrome Extension API
Injeção cirúrgica de Content Scripts, mantendo a performance da ferramenta V8 isolada.
CSS Custom Props
Tokens de cor flexíveis (Slate, Emerald, Amber) para o Design System Bento.
